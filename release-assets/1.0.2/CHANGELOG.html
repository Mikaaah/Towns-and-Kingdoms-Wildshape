WILDSHAPE — 1.0.2

More reliable world generation, cleaner caves and updated river compatibility.

Minecraft 1.21.1 · NeoForge · Java 21

World generation and stability

  • Fixed the concurrent terrain-cache eviction crash reported in TNK3 issue #158. Eviction now sorts fixed access-time snapshots, removes entries by identity and keeps published terrain data safe for readers still using it.
  • Fixed underground aquifer sources and their clay beds surviving inside newly carved chambers as floating shelves. Surface water, authored cavern lakes, waterlogged blocks, structures and protected cave habitats retain their safeguards.
  • Water and lava exposed by custom cave carving now receive normal fluid updates.
  • Surface-height checks now use the chunk's actual solid ground, fixing missing topsoil when density shaping or structure adjustment differs from the predicted terrain height. Native biome materials, including Nature's Spirit highland terracotta, are preserved.

Streams Reflowing compatibility

  • Added explicit support for Streams Reflowing 2.17.3 and 2.17.4, alongside the existing 2.15.2, 2.16.2 and 2.17.1 bindings.
  • Restricted the Streams carving guard to Wildshape's native raised-water volumes. Streams can now clear its own water and obsolete sources outside those volumes.
  • Carving state is restored after exceptions and nested features. Unrecognized Streams releases no longer activate the legacy actual-water hooks.

Updating and verification

Replace the previous Wildshape JAR and restart Minecraft. Terrain corrections affect newly generated chunks; saved terrain is not rewritten. The wildshape registry namespace is unchanged from 1.0.0 and 1.0.1.

Verification: The build, 55 focused regression tests and 25 flow checks passed. Isolated NeoForge 21.1.266 server fixtures passed generation, saving and reloading with Wildshape alone and with Streams 2.17.4, C2ME 0.124 and Nature's Spirit 2.3.2. Both reported chunks reached FULL and retained matching saved block palettes after reload.

Full-pack graphical inspection and a replay using the original world's seed and preset remain unverified. See the audit and verification record for details.
