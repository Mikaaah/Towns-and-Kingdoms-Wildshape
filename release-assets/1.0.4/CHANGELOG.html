WILDSHAPE — 1.0.4

World generation and search performance fixes.

Minecraft 1.21.1 · NeoForge · Java 21

Structure searches

  • Fixed broad structure searches performing expensive river-network surveys on the server thread.
  • Structure-locator candidate checks now use a coarse terrain and climate estimate. Ordinary biome searches retain their existing terrain sampling.
  • Separated cached structure estimates from normal terrain queries and restored temporary search state after nested calls and failures.

SkyLands generation

  • Stopped remote SkyLands island-anchor checks from requesting complete filtered Wildshape terrain tiles.
  • Applied the same fix to island structure-intersection checks and neighboring island probes.
  • Retained SkyLands’ native island placement, structures, biome injection and configuration. SkyLands remains an optional installation.

Terrain calculations

  • Reused identical coastline calculations at biome-region centres instead of repeating them for every terrain cell.
  • Kept cached values specific to their world and worker, preserving the calculated climate values.

Updating

Replace the previous Wildshape JAR with Wildshape 1.0.4 on the client and server, then restart.

Existing wildshape worlds retain their saved presets, noise height, terrain settings and generated chunks. A world created with Wildshape 1.0.0 does not require regeneration for this update. The optional SkyLands build-ceiling adjustment is retained.

C2ME is optional. Server performance also depends on the installed mods, world preset and number of chunks being generated; these fixes do not guarantee a particular TPS.
