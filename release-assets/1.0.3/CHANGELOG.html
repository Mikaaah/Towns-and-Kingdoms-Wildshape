WILDSHAPE — 1.0.3

Optional SkyLands compatibility for new and existing Wildshape worlds.

Minecraft 1.21.1 · NeoForge · Java 21

SkyLands integration

  • Added compatibility with SkyLands NeoForge Port 0.9.4, supplying the Overworld build space required for its native sky islands and foliage.
  • Existing Wildshape preset packs receive the height adjustment at startup. The saved preset, terrain noise, world depth, cave and river settings are retained.
  • Higher configured ceilings are preserved. Other dimension-type resources remain under their native ownership.
  • SkyLands keeps its own biome injection, island generation, structures, spawn rules, loot and configuration. No additional hard dependency or bundled third-party mod is introduced.

Updating

Replace the previous Wildshape JAR on the server and clients, install SkyLands and its normal dependencies separately, and restart. Existing saves using the wildshape namespace keep that identity.

New chunks only: existing generated and pregenerated chunks do not gain islands. Explore beyond the pregenerated area. Keep a backup before adding a worldgen mod.

Earlier world-creation, cache, cave-fluid and Streams fixes remain included. Worlds using the former ultraterraforged namespace still need their separate migration.

Verification

The NeoForge build, release identity check, 53 focused regressions and 25 pure flow/search checks passed. Native islands and a Y=527 marker saved and reloaded, while the sampled existing chunk and saved preset stayed unchanged. Startup without optional mods also passed. Full graphical client and original-server seed/preset verification remain separate checks.
