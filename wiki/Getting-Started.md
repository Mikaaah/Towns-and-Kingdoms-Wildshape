# Getting started

1. Set up **Minecraft 1.21.1** with **NeoForge** and **Java 21**.
2. Put the Wildshape JAR in your `mods` folder.
3. Create a new world and select **Wildshape** as the world type.

On a dedicated server, add this to `server.properties` before creating the world:

```properties
level-type=wildshape:wildshape
```

Wildshape saves its configuration in `config/wildshape/`.
