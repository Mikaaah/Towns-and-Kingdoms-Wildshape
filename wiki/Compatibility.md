# Compatibility

The FML mod ID and resource namespace are `wildshape`; configuration uses `config/wildshape/`. This identity begins with 1.0.12-beta.2 and requires a fresh world or a separate registry migration. The NeoForge edition integrates optional Alex’s Caves and Streams Reflowing adapters. Remove separate `tfacfix` and `utfstreams` JARs when using the integrated equivalents. Only NeoForge 1.21.1 is built and supported.

Read [the compatibility matrix](https://github.com/Mikaaah/Towns-and-Kingdoms-Wildshape/blob/main/docs/TNK3_COMPATIBILITY.md) and [Streams setup](https://github.com/Mikaaah/Towns-and-Kingdoms-Wildshape/blob/main/docs/TNK3_STREAMS_REFLOWING.md).
