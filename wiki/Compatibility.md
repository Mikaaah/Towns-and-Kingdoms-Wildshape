# Compatibility

Internal mod ID, namespaces and configuration paths remain `ultraterraforged`. The NeoForge edition integrates optional Alex’s Caves and Streams Reflowing adapters. Remove separate `tfacfix` and `utfstreams` JARs when using the integrated equivalents. Fabric does not include those NeoForge adapters.

Read [the compatibility matrix](https://github.com/Mikaaah/Towns-and-Kingdoms-Wildshape/blob/main/docs/TNK3_COMPATIBILITY.md) and [Streams setup](https://github.com/Mikaaah/Towns-and-Kingdoms-Wildshape/blob/main/docs/TNK3_STREAMS_REFLOWING.md).
