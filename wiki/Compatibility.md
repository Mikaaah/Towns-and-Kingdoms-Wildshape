# Compatibility

**Current edition: Wildshape 1.0.0 · NeoForge 1.21.1 · Java 21.** The mod ID and resource namespace are `wildshape`; configuration uses `config/wildshape/`.

| Integration | Supported current pairing |
| --- | --- |
| Streams Reflowing | Verified adapters for 2.15.2, 2.16.2 and 2.17.1 |
| Flow Control 0.2.2 | Streams Reflowing 2.16.2 |
| Flow Control 1.0.0 | Streams Reflowing 2.17.1 |
| Alex's Caves | Integrated optional NeoForge adapter; keep the actual cave mod and its dependencies installed |

Remove the superseded `utfstreams`, `tfacfix` and `utfoptimizer` adapters when using their integrated equivalents. Keep Flow Control for its tools. Use one terrain generator JAR.

**Use a fresh world when replacing an `ultraterraforged` build.** Importing settings does not migrate registry references in an old save or datapack.
