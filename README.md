**Minecraft 1.21.1 · NeoForge · Java 21**

Wildshape is a world generation mod for Towns & Kingdoms. It adds sweeping terrain, winding rivers, and large connected caverns with lush, dripstone, and lantern styles. It supports native biomes from Biomes O’ Plenty, Regions Unexplored, and Nature’s Spirit, and integrates with Streams Reflowing, Alex’s Caves, and SkyLands when installed.

## Installation

1. Set up **Minecraft 1.21.1** with **NeoForge** and **Java 21**.
2. Put the Wildshape JAR in your `mods` folder.
3. Create a new world and select **Wildshape** as the world type.

On a dedicated server, add this to `server.properties` before creating the world:

```properties
level-type=wildshape:wildshape
```

See the [wiki](https://github.com/Mikaaah/Towns-and-Kingdoms-Wildshape/wiki) for terrain presets, compatible mods, and troubleshooting.
