# Towns & Kingdoms Wildshape

Wildshape changes world generation with varied terrain, winding rivers, and large connected caverns. Select **Wildshape** as the world type when creating a world.

Requires Minecraft 1.21.1, NeoForge 21.1.262 or newer, and Java 21.
